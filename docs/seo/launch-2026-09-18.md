## Measurement

Vercel Web Analytics is already enabled on the Hobby project; the new client integration sends allowlisted public pageviews, stripping query strings and fragments. Custom events are implemented in first-party PostgreSQL counters because Vercel custom events require a paid plan.

Five report clusters: state_requirements, course_topics, mate_act, national_guides, product_category. Anonymous CTA/course clicks are counted by source page, coarse channel and UTC date. Requests reject private or unknown paths, arbitrary channels, fake registration/activation event names and foreign origins. An in-memory burst limit is best effort, not an anti-bot guarantee. Click totals are events, not unique users.

The 30-day first-touch cookie stores only an allowlisted page, cluster, coarse source and timestamp. Campaign parameters are reduced to a boolean; query strings/search terms are never stored. Secure SameSite=None on HTTPS preserves this non-authentication cookie through Apple's cross-site callback. Authentication cookies and auth/security behavior are unchanged.

Auth.js createUser records a new web account and its acquisition source transactionally. Activation means an attributed account has an active license plus at least one COMPLETED certificate or a manually verified MANUAL record, observed on a dashboard visit. The server rechecks these conditions and claims the event once with a conditional update inside the counter transaction. Deletion/recreation of certificates cannot recount an activation. No account IDs, names, license details or certificate data enter the aggregate table. Attribution fields are deleted with an account; aggregate totals remain. DNT suppresses web measurement.

Limits: blocked JavaScript, DNT, cookie deletion, first-touch expiration, cross-device signup, native app registration and activation without a web dashboard visit can undercount. First-touch attribution is not causal lift. Do not report absent observations as zero conversions for all users. Search Console impressions/clicks and website sessions/events have different definitions.

Read aggregate counters with `DATABASE_URL=… node scripts/seo-report.mjs 28` (supply the intended database through a secure environment; never commit credentials). It runs a READ ONLY transaction and returns page/cluster/channel/event counts. Filter channel=organic_search for attributed search conversions. Registration and activation are event-date cohorts, so same-period division is not a true cohort conversion rate.
